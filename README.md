# 정육 해체장 (Butcher Game)

고리에 매달린 지육을 칼선을 따라 드래그해서 부위별로 해체하는 웹 3D 정육 시뮬레이션.
설치도 로그인도 없다 — 브라우저에서 바로 열린다. **휴대폰에서도 된다.**

### ▶ https://gkdnjsdls1-stack.github.io/butcher-game-web/

## 무엇을 하는 게임인가

**1차 대분할** — 닭 한 마리(양쪽 면 10부위) · 돼지 반 마리(7부위) · 소 반 마리(사분 체절 뒤
9부위) · 사슴(톱 없이 솔기 따라 4부위, 박힌 산탄 3발을 찾아 빼야 한다).

**2차 소분할 27덩어리** — 1차로 뗀 부위를 작업대에 눕히고 위에서 내려다보며 소분할한다.
열일곱 덩어리는 작은 부위를 뗀 뒤 주문대로 정량으로 썰고, 열 덩어리는 썰지 않고 부위로만
가른다. 1차를 끝내면 결과 화면에서 바로 이어진다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 드래그 | 칼선을 따라 자르기. 여러 번 나눠 그어도 된다 |
| Space / 아래 "뒤집기" | 지육 뒤집기 |
| Q / W | 칼 / 톱 (톱을 쓰는 동물만) |
| 고기를 짧게 누르기 | 박힌 산탄 빼기 (사슴). 안 빼고 떼면 파지육 |
| 드래그 (2차 썰기) | 덩어리를 가로질러 한 줄씩 밀면 그 자리에서 한 토막이 떨어진다 |

- 노란 선은 칼, 하늘색 선은 톱. 톱은 앞뒤로 여러 번 문질러야 썰린다.
- 관절이 아닌 곳에서 뼈를 치면 칼이 튕긴다. 순서상 아직 닿지 않는 부위에는 칼이 안 들어간다.
- 칼선에서 크게 벗어나면 파지육이 되어 다짐육 값으로 팔린다.
- 숙련도가 오르면 가이드가 점점 사라진다 (기록은 브라우저에만 쌓인다).

피는 나오지 않는다. 진열대 고기 수준으로 그린다.

## 기술

빌드 과정이 없는 한 파일짜리 웹 앱이다 (`index.html`). [Three.js](https://threejs.org/) 0.160을
CDN에서 불러오고, 텍스처는 전부 캔버스로 그린다 — 외부 이미지가 없다. 부위 메시는 블렌더로
자른 `.glb`를 base64로 담은 `models/*.json`에서 온다.

이 저장소는 **게임만 담은 사본**이다. 모델을 만드는 블렌더 스크립트와 개발 기록은 따로 둔다.

맞는 무료 소·사슴 지육 모델이 없어서 내린 결정이다.
